# 架构决策记录（ADR）

记录这个项目里**不看注释就猜不出来**的取舍。每条包含背景、决策、理由，
以及「代价与已否决的替代方案」——后者往往比结论更有用。

新增 ADR 时请沿用同样的结构。如果一个决策的「为什么」能写进代码注释，就先写注释；
只有当理由涉及被否决的替代方案、或跨多个文件时，才值得单独立一篇。
